# printing-digital · 光与电（D1–D4）

印刷史家族第 7 个开发动画（spec 10 §3 P6）。无版直印跃迁：静电六步 → 喷墨微滴 → 汉字难题 → 王选拉开 500–1000× 压缩跨越。

| id | 名称 | 拍点 |
|----|------|------|
| D1 | 静电的魔法 | 激光扫过处电荷熄灭、碳粉如铁屑吸附显影（鼠标=激光） |
| D2 | 喷墨微滴 | 皮升墨滴微距弹射慢镜头（2–4 pL） |
| D3 | 汉字的绊脚石 | 镜头从一座铅字架拉远成字模之海 |
| D4 | 王选的跨越 | 轮廓线收拢成一个汉字、铅字架整体退场 |
