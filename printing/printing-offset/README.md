# printing-offset · 胶印（O1–O4）

印刷史家族第 6 个开发动画（spec 10 §3 P5）。平版跃迁：油水分离 → 橡皮布两次转印 → CMYK 全彩。

| id | 名称 | 拍点 |
|----|------|------|
| O1 | 石版的秘密 | 水膜与油墨在平面上楚河汉界对峙 |
| O2 | 从照片到网点 | 照片在网屏下碎成万点的分解瞬间 |
| O3 | 橡皮布与三滚筒 | 水膜被橡皮布甩飞的水雾粒子（three.js） |
| O4 | 全彩印刷工厂 | 四色网点叠加显影出全彩照片的瞬间 |
