# ☀️ 太阳能电池 — 从光子到电流（5 章交互旅程）

一个四则混用的 three.js 教学应用：从硅原子一路讲到**世界纪录 27.81%**。
第 5 章的所有数字都经过在线核实（2026-09-17），标注了认证机构。

> **入口**：`index.html`（模块化，开发用）/ `solar-cell.html`（单文件离线版，`python3 build.py` 生成，~1.1 MB）

## 章节

| # | 章节 | 你玩什么 |
|---|------|---------|
| 1 | 🧊 从原子到晶体 | 看硅原子排成钻石晶格、共享电子成共价键 |
| 2 | 📊 能带从哪来 | 10²² 条能级挤成"带"；带隙 1.12 eV |
| 3 | 🔧 分离装置：PN结 | 掺磷(2,8,5)→n 型、掺硼(2,8,3)→p 型、合成 PN 结看内建电场 |
| 4 | ✨ 光子的一生 | 发射不同波长的光子：亚带隙穿透 / 激发电子-空穴对 / 电场分离 / 点亮灯泡 |
| 5 | 🌍 真实世界 | 电池层状截面（逐层点击）、光阱光子雨（35%→2% 反射）、效率天平（100% 阳光的完整去向） |

## 第 5 章用到的真实数字（全部有出处）

| 事实 | 数值 | 出处 |
|------|------|------|
| 硅带隙 | 1.12 eV（λ > 1100 nm 的光子穿透） | 教科书共识 |
| 吸收深度 1/α | 550nm→1.6 μm；800nm→12 μm；**1000nm→156 μm**；1100nm→~2.9 mm | Green & Keevers 1995（pveducation 转载） |
| 裸抛光硅反射率 | >30%（由 n 数据 Fresnel 计算：400nm 48% ↔ 1100nm 31%） | pveducation + Green & Keevers n 数据 |
| 绒面+减反射膜后 | ≈2%（工业典型值，示意） | 行业实践；75nm SiNx n≈2.05 四分之一波长 |
| 光谱损耗 | **19% 亚带隙穿透 + 33% 热化** → 光谱上限 48% | Wikipedia Shockley–Queisser limit |
| 单结理想极限 | 33.7% @ 带隙 1.34 eV；硅辐射复合极限 ≈32% | 同上（Rühle 2016 带背镜 33.16%） |
| 硅物理极限 | **29.4%**（计入俄歇复合） | Richter et al. 2013, IEEE J. Photovoltaics |
| 单结硅世界纪录 | **27.81%**（LONGi HIBC，ISFH 认证，2025-04-11；历程 26.81→27.30→27.81） | LONGi 官方 / taiyangnews |
| 量产商用电池 | ≈24%（组件纪录 25.4%，Fraunhofer ISE） | Wikipedia Solar cell efficiency |
| 钙钛矿/硅叠层 | **34.85%**（NREL 认证 2025-04，双结突破单结极限，理论 ~43%） | LONGi 官方 / pv-magazine |

光子雨的概率模型：P(吸收) = 1 − exp(−α·L)，α 取 Green & Keevers 实测值，
L = 150 μm（裸片单程）或 ×2.6（绒面+背反射多程）——**不是逐光线追踪**，是诚实标注的示意。

## 运行

```bash
# 模块化版（需本地 http 服务）
python3 -m http.server   # 然后访问 solar-cell/

# 单文件版（file:// 直接双击即可）
python3 build.py         # 需要 esbuild（PATH 中）；生成 solar-cell.html
```

## 文件

```
solar-cell/
  index.html            # 模块化入口
  js/core.js            # 场景/动画队列/共享几何（晶格、载流子、光子颜色与能量）
  js/ch1..ch4*.js       # 晶体 / 能带 / PN结 / 光子的一生
  js/ch5_real.js        # 真实世界：截面 · 光阱 · 效率天平
  js/main.js            # 章节路由 + 渲染循环
  vendor/               # three@0.160 本地副本（离线）
  build.py              # esbuild 打包 → 单文件 solar-cell.html
```
