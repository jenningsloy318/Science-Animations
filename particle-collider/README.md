# Collider Explorer 对撞机探秘

An interactive, **Three.js** particle-collider experience inspired by **CERN's Large Hadron
Collider** and the **ATLAS detector** — packaged as **one self-contained HTML file** that runs
fully offline. **Bilingual: 中文 / English** — toggle with the **EN / 中文** button in the top
bar; the whole UI, education panel and captions switch live.

一个受 CERN 大型强子对撞机（LHC）与 ATLAS 探测器启发的交互式 Three.js 科普可视化，
可完全离线运行。内置中英双语切换（顶栏 EN / 中文 按钮，全界面即时生效）。

> **What it is / isn't.** This is an independent educational visualization. It is **not**
> affiliated with or endorsed by CERN. Geometry is deliberately **simplified** (proportions —
> especially inner radii and the ring radius — are exaggerated so every layer stays readable).
> All collision events are **synthetic**, generated from physics-inspired math, never real
> detector data. Facts are sourced from official CERN pages (home.cern, atlas.cern).

## Quick start

**Modular (recommended):** open **`index.html`** — it loads `js/*.js` and `vendor/three.min.js`
as separate files (plain script tags, so `file://` works; no server needed).

**Single file:** `collider.html` is the same app inlined into one portable file for sharing.
Rebuild it any time with:

```bash
python3 build.py        # inlines index.html + js/ + vendor/ → collider.html
```

## The three views

| View (tabs / keys) | What you see |
|---|---|
| **Detector** `1` | A layered, ATLAS-inspired detector with ~37,000 individually placed parts (straw tubes, silicon modules, calorimeter plates, magnet coils, muon chambers…). |
| **Accelerator** `2` | The 26,659 m LHC ring compressed ≈60×, two counter-rotating bunch trains, 8 straight sections, the four experiments, RF / beam-dump / collimation points. |
| **Collisions** `3` | A schematic cut-away with **synthetic** events: charge-curving helix tracks (curvature ∝ 1/p_T), jet energy towers, long gold muon tracks, a missing-E_T arrow. |

## Six-stage disassembly (Detector view)

The detector unfolds from the outside in — from the large end-cap wheels and magnets down to
the individual sensor modules:

1. **Muon wheels** — end-cap “big wheels” slide out; barrel chamber banks fan outward
2. **Toroid magnets** — 8 barrel coils + 2 end-cap toroids pull apart
3. **Calorimeters** — EM / tile barrel halves split; LAr end-caps, HEC and FCAL retreat
4. **Solenoid & structure** — the 2 T solenoid opens along its seam; supports spread
5. **TRT + SCT** — straw layers and silicon layers separate radially; end-cap disks glide out
6. **Pixel + beam pipe** — pixel layers and disks drift away, exposing the interaction point

**Controls:** `scroll` over the canvas scrubs the disassembly; `Space` play/pause; `R` reverses
(direction becomes *assembly*); `30 / 60 / 90 s` buttons set the playback duration; the scrubber
and the six stage chips jump anywhere; `← / →` step stages. A camera pull-back is coupled to the
explode progress so everything stays framed.

**System switches:** the left panel toggles each of the 10 systems on/off and shows how many
parts are rendered for it (hover for the real CERN figures; click the name to focus the camera
and read about that system).

**Accelerator extras:** `▶ Camera flight` (or `F`) flies you along the ring past ATLAS, CMS,
ALICE and LHCb with captioned facts; drag cancels. The beam-speed slider scales the bunch trains.

**Collisions extras:** `Trigger event` (or `E`) fires a fresh synthetic event; auto-renew is on
by default; live HUD shows event #, track / jet / muon counts and ΣE_T.

## Implementation notes

- **Performance:** all repetitive hardware is drawn with `THREE.InstancedMesh` (≈40 draw calls
  for ~37k parts). Tens of thousands of parts are *individually animated* on the GPU via a
  small emissive “shimmer” wave injected into the standard material (`onBeforeCompile`), using
  per-instance world position — zero CPU cost per part. Beams are shader-driven point sprites.
- **Staged explode:** each part carries a base transform plus a per-stage direction/amplitude;
  scroll/playback recomposes instance matrices only for stages whose progress changed.
- **Lighting:** procedural PMREM environment (for metallic reflections), ACES filmic tone
  mapping, warm key + cool rim + gold fill, fog and a vignette.
- **Offline & portable:** no fonts, no CDN, no build-time dependencies (build script is stdlib
  Python). Classic scripts, so `file://` works for both the modular entry and the single file.

## Collision sequence 对撞过程动画

Every trigger plays a narrated, step-by-step sequence (captions in the current
language): two protons race in along the beam pipe → flash impact (E = mc²) →
quarks and gluons burst out → hadronization into jets → each detector layer
flashes in radial order (pixel → tracker → calorimeters → muon chambers) →
event measured. The outer detector skins (EM / tile barrels) are rendered
semi-transparent so the hollow onion structure and the beam axis stay visible.

每次触发都会播放一段分步讲解动画（字幕跟随当前语言）：两个质子沿束流管相向飞入 →
对撞闪光（E = mc²）→ 夸克胶子喷出 → 强子化形成喷注 → 探测器各层由内向外依次闪亮 →
事件测量完成。外层筒壁（电磁/强子量能器）做了半透明处理，
空心中轴与层层套叠的结构一目了然。
