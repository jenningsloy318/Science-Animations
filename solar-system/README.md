# 太阳系探索者 (Solar System Explorer) — 3D 漫游与航天轨道规划系统

基于 **Three.js** 与现代 WebGL 物理渲染构建的三维交互式太阳系模拟与航天轨道规划平台。

---

## 🪐 系统特色与天体配置

### 1. 恒星与八大行星系统 (Eight Planets)
- **太阳 (Sun)**：发光等离子体球、对流米粒组织、太阳黑子与动态日冕晕。
- **水星 (Mercury)**：密布撞击坑、高地与卡洛里斯撞击盆地。
- **金星 (Venus)**：浓厚硫酸云层与人字形急流条带、逆行自转。
- **地球 (Earth)**：蔚蓝海洋、生机大陆、透明大气白云旋涡与极地冰盖。
- **火星 (Mars)**：铁锈红色地表、大峡谷水手峡与南北极水冰干冰极冠。
- **木星 (Jupiter)**：绚烂的赤道/温带云带、反气旋大红斑（Great Red Spot）。
- **土星 (Saturn)**：典雅金黄色云层与高拟真双面反射卡西尼缝土星环系统（A环、卡西尼环缝、B环、C环）。
- **天王星 (Uranus)**：淡青色冰巨星、极度奇特的 97.8° 卧式侧向滚动自转及竖立光环。
- **海王星 (Neptune)**：深邃皇家钴蓝色、大黑斑风暴与甲烷卷云。

### 2. 二十二颗核心天然卫星 (Twenty-Two Moons)
真实还原了 22 颗具有代表性的太阳系卫星，以正确的轨道半长轴和公转周期依附于各自母星运行：
- **地月系 (1 颗)**：月球 (Moon)
- **火星系 (2 颗)**：火卫一 (Phobos)、火卫二 (Deimos)
- **木星系 (5 颗)**：木卫一·伊奥 (Io)、木卫二·欧罗巴 (Europa)、木卫三·盖尼米德 (Ganymede)、木卫四·卡里斯托 (Callisto)、木卫五 (Amalthea)
- **土星系 (7 颗)**：土卫六·泰坦 (Titan)、土卫二·恩克拉多斯 (Enceladus)、土卫一·死星 (Mimas)、土卫三 (Tethys)、土卫四 (Dione)、土卫五 (Rhea)、土卫八·阴阳星 (Iapetus)
- **天王星系 (5 颗)**：天卫五·维罗纳断崖 (Miranda)、天卫一 (Ariel)、天卫二 (Umbriel)、天卫三 (Titania)、天卫四 (Oberon)
- **海王星系 (2 颗)**：海卫一·逆行柯伊伯带俘获星 (Triton)、海卫八 (Proteus)

### 3. 简易航天轨道规划 (Hohmann Transfer Spaceflight Planner)
- **物理引力算法**：依据开普勒行星运动定律与霍曼转移椭圆轨道理论（Hohmann Transfer Orbit）。
- **参数解算**：
  - 发射加速推进量需求（$\Delta v_1$）
  - 目标入轨减速推进量需求（$\Delta v_2$）
  - 总速度增量（Total $\Delta v$，km/s）
  - 转移飞行耗时（天 / 年）
  - 发射窗口最佳相位角（Phase Angle）
- **动态三维飞行演示**：
  - 绘制金色虚线日心椭圆转移轨道与交会目标标记；
  - 具有金色隔热层、太阳翼帆板与高增益天线的 3D 探测器模型；
  - 离子发动机点火蓝色等离子喷流与飞行轨迹流光尾迹；
  - **飞船跟飞视角 (Chase Cam)**：以第三人称伴随视角直击深空穿梭全过程；
  - 飞行实时遥测 HUD（速度、剩余距离、任务天数进度、入轨捕获状态）。

### 4. 视角与探索控制
- **自由旋转/缩放**：鼠标左键旋转、滚轮缩放、右键平移。
- **天体居中跟踪锁定**：点击任意天体或在左侧列表选择，镜头平滑切换并随天体公转动态同步锁定跟随。
- **预设视角**：全景、内行星、地月系、木星系、土星环、巨行星一键直达。
- **时间机器**：支持暂停、1x ~ 5000x 任意时间倍率跃迁。
- **视觉选项**：行星轨道显示/隐藏、卫星轨道显示/隐藏、天体标签显示/隐藏、天体比例放大滑块。

## 🚀 启动与访问

本地开发与运行（利用本站统一静态服务器 Caddy）：
```bash
# 在 science 根目录启动服务
make start    # 或 make dev

# 浏览器访问：
http://localhost:8321/solar-system/
```
或直接通过主站首页 `http://localhost:8321/` 点击“太阳系探索者”卡片进入。
