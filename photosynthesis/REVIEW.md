## P0 — 破坏核心视图

### 1. OrbitControls 交叉污染，light 视图无法复位
四个视图共用 `#gl` canvas，却各建一个 OrbitControls（`js/story.js:24`、`js/chloroplast.js:23`、`js/light.js:36`、`js/spectrum.js:41`）。在任何视图拖拽会同时转动其它三个视图的相机。story/chloroplast 靠每帧 lerp 回 HOME 自愈；light/facts 没有。实测：facts 视图轻拖后切回 light，整台机器倾斜 ~40°，且 light 视图没有 ⟲ 复位按钮，用户无法恢复。

### 2. light 视图默认取景：拼糖环 + 电池库存被说明面板遮挡
相机 target x=6 偏右；1600×900 下面板盖住 x≈9 以右，环在 x=12、电池堆在 x≈8.4/15.6。环约 60% 在面板后，`下半·拼糖循环` 标题被切半。"闭环同屏"是这个视图的主旨，恰好是被遮的部分。

### 3. light 视图标签互相重叠
- 顶部组件行：`b6f·泵 H⁺`（x=-0.7）/ `ATP 合酶`（x=3.0）/ `PSI·第 2 次充电`（x=8.0）经 1.35×1.5 缩放后每个宽 5–8 世界单位，连读成一串（`js/light.js:170-174`）；FNR 引线横穿该行。
- `光子 = 能量包裹`（y=7.2）压在 `上半·光反应` 标题（y=6.6）上（`js/light.js:213`）。
- 下半区 `满电池↓送去拼糖` / `电池库存（满）` / `↑空电池回膜上再充电` 互相叠（`js/light.js:195-202`）。

## P1 — 明显可见错误

### 4. 糖块堆叠 bug（story 视图）
`spawnSugar` 用 `sugarPile.children.length` 做序号，但糖块 `scene.add(m)` 从未加入 sugarPile（`js/story.js:164-177`）→ 序号恒为 0，所有糖块生成在同一坐标。实测 HUD 计 2 块、画面只见 1 块，糖堆不生长。生成点 (-1.7, 0) 藏在叶子轮廓内，而糖标签在 (-7.6, 5.6)，标签指向空白。

### 5. chloroplast 导览第③站：`周围液体 = 基质` 标签在屏幕外
标签 y=-12（`js/chloroplast.js:140`），TOUR[2] 取景只到 y≈-6。每站停留仅 1.6s（`js/chloroplast.js:198`），读不完就跳站。面板①两标签相碰（`js/chloroplast.js:59-62`）。

### 6. facts 三档取景遮挡
- 光谱：`红 662nm` 标签被面板完全挡住（`js/spectrum.js:80`）——红峰是本页结论之一。
- 阶梯：整体右移，`太阳能板纪录` 柱与 27.8% 撞面板；标题 y=17 在画面外，本档无标题（`js/spectrum.js:101`）。
- 地球：撑满全屏，`120 Gt` 标签不可见；`O₂ ≥ 一半来自海洋浮游植物` 被底部控制条盖住（`js/spectrum.js:120-125`）。

## P2 — 认知层面 gap

- **三套 ①②③ 编号同屏撞车**：页签①–④、放大级别①②③（场景内标签）、`光反应②`/`合成循环③` 里的步骤序号。同一屏 `③ 再放大：叶绿体` 的 ③ 与 `合成循环③` 的 ③ 无关。建议场景内编号改用名字。
- **电子先于光子出发**（`js/light.js:456-461`）：光子尚在半空，电子已沿管道走 ~1.2s，因果画面上是反的。应等光子落地再生成电子。
- **水的因果断线**：light 视图水滴飘 1s 原地消失，无进入 PSII 的动作；story 视图糖产出仅由 CO₂ 驱动，水被计数但不参与任何产物。
- **ATP:NADPH 产量失衡**：模拟产出比 ≈1.05:1（0.47 vs 0.45 /s），拼糖消耗 1.5:1 → 45s 时 NADPH 堆 8、ATP 剩 2，机器长期等 ATP、紫色库存无限堆积。满池 atpFlow 从 2.2 调到 ~3.2 可配平（`js/light.js:542`）。
- **图例缺口**：ADP/NADP⁺ 空电池（棕/淡紫）不在图例（`index.html:122-129`）；光谱页叶绿素 a/b 两组绿柱无图例区分（`js/spectrum.js:59-73`）。
- **拖拽回弹**：story/chloroplast 非导览态每帧 lerp 回 HOME（`js/story.js:249-252`、`js/chloroplast.js:216-219`），实测拖拽后 1.5s 内被拉回，与"随时拖动自己看"矛盾。
