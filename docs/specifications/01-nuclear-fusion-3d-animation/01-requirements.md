## Non-Functional Requirements

- Performance: target ≥ 60 fps at 1080p on integrated graphics; total animated particle count (plasma electrons + nuclei) capped around 2,000; renderer pixel ratio capped at min(devicePixelRatio, 2); geometries/materials disposed on phase rebuild to avoid GPU memory leaks.
- Learning accessibility (color-blind safe): proton / neutron / electron must be distinguishable by more than hue alone — differentiated by size (proton and neutron similar nuclear scale, electron visibly tiny) plus on-canvas or legend labels 质子/中子/电子; palette choices (warm red proton, cool gray-blue neutron, small bright electron) remain distinguishable under common color-vision deficiencies.
- UI consistency: all controls carry title tooltips (as in ion-thruster-3d), narration and labels in Chinese with the card title bilingual, layout responsive via viewport meta (works on tablet width), keyboard-focusable buttons.
- Compatibility & degradation: works in current Chrome/Firefox/Safari; if WebGL is unavailable the page shows a Chinese explanation message instead of a blank canvas.
- Security/hygiene: no eval, no user text input, CDN pinned to the exact three@0.160.0 version (same pin as ion-thruster-3d), no writes to or modifications of the existing Caddyfile or other pages beyond adding the root index.html card.
