## Non-Functional Requirements

- 性能：单一 requestAnimationFrame 主循环；全场景粒子硬上限 ≤ 2000（沿用兄弟站 MAX_PARTICLES 约定，优先合并绘制调用）；目标中端笔电 60fps；纯静态资源，外部域名仅限继承的 cdn.jsdelivr.net/three@0.160.0 与 es-module-shims@1.10.0（import map 逐字一致，不新增第三方来源），file:// 直开可用，首帧 < 2 秒。
- 可访问性：全部工具栏/底栏控件键盘可达且有可见焦点态；图标按钮具备描述性 title/aria-label；状态切换（自动换幕、暂停）同步 aria-pressed 与文字标签；粒子身份主要靠大小与图例区分而非仅颜色（镜像兄弟站低色盲依赖约定）；正文对比度满足 WCAG AA。
- 健壮性：WebGL2/上下文不可用时优雅降级显示文字提示（不得白屏/未捕获异常）；暂停期间时钟与粒子完全冻结、恢复后从冻结点原样继续；未知 gotoPhase 键静默容错。
- 安全：零新增网络请求与远程取数、不使用 eval/new Function；测试与生产均零第三方依赖（node:test + node:assert/strict，浏览器端仅既有 three 模块与 es-module-shims 加载器）。
- 语言与受众：界面与讲解文案以中文为主、术语附英文（延续 Nuclear Fission 核裂变 双语卡片风格），解说面向初学者使用生活化类比，科学常数严格限定在 AC-05 逐字锚定范围内。
