## 二、第 0 层（地基）：天文学家真正能测量的只有四样东西

天文台没有"恒星年龄仪"。一台望远镜 + 探测器，最终输出只有四类原始数据：

| 可观测量 | 物理量 | 测量工具（历史→现代） |
|---------|--------|---------------------|
| **方向（角度）** | 视位置、视差角 p | 肉眼四分仪 → 望远镜测微器 → 依巴谷卫星（毫角秒）→ 盖亚卫星（微角秒，19 亿颗星） |
| **时间** | 周期、到达时刻、光变曲线 | 肉眼计时刻 → 机械钟 → 光电倍增管 → Kepler/TESS 秒级测光 |
| **亮度** | 视星等 m（流量） | 目视估计 → 照相底片 → CCD |
| **颜色/波长** | 谱线位置 λ | 棱镜 → 光栅摄谱仪 → 光纤多目标光谱仪（LAMOST、DESI） |

**第一性原理陈述：**
天体的一切其他性质——距离、速度、温度、成分、质量、半径、年龄——都不是直接测量，
而是从这四个可观测量 + 实验室物理定律 **推导** 出来的。每条推导链都是本文档的一层。

**知识栈总览（推导方向：从下往上）：**

```
L7  宇宙年龄 13.787 Gyr、回看时间、CMB      ← L2 距离 + L4 红移 + 广义相对论
L7b 应用闭环：卫星（称重/追踪/GPS）        ← L1+L3+L4 的工具全部复用（10 号文件）
L6  行星年龄：放射性钟 4.567 Gyr（太阳系）   ← L3 光谱(实验室同位素) + 核物理
L5  恒星年龄：主序寿命/转折点/星震学…       ← L3 温度光度 + L2 距离 + 核物理
L4  多普勒频移 → 速度 → 质量/暗物质/膨胀    ← L3 波长 + 波动方程
L3  光谱 → 温度/成分/光度                   ← L1 光 + 量子力学
L2  距离：视差 → 标准烛光 → 阶梯            ← L0 角度 + 亮度
L1  光速有限 c：光 = 时间机器               ← L0 时间 + 木星月食几何
L0  可观测量：角度、时间、亮度、波长        ← 一切的地基
```

## 四、一句话结论速查

- **光速** c = 299,792,458 m/s（1983 年起定义为精确值）。1676 年罗默用木卫一食迟到 22 分钟第一次测出 c（≈2.2×10⁸ m/s）。
- **看到过去不是比喻，是几何必然**：看到 1 秒前的月亮、8 分 20 秒前的太阳、254 万年前的仙女座。
- **距离** = 视差（1 秒差距 = 1 角秒视差 = 3.26 光年，只到 ~千秒差距）+ 标准烛光外推到宇宙边缘。
- **多普勒** Δλ/λ ≈ v/c；哈泼斯-哈普克（HARPS）光谱仪精度 0.97 m/s，能"听"出地球让太阳晃 9 cm/s。
- **恒星年龄**：质量是寿命的遥控器（t ∝ M⁻²·⁵），星团转折点是目前最准的恒星"身份证年龄"。
- **行星年龄**：放射性衰变是核内沙漏，λ 不受化学/温度/时间影响（有 20 亿年天然反应堆和 16.8 万光年外钴-56 衰变为证）；太阳系 4.567 Gyr。
- **宇宙年龄** 13.787 ± 0.020 Gyr（普朗克卫星 CMB + ΛCDM），与最老球状星团（12–13.5 Gyr）、最老白矮星、宇宙编年星相互咬合。
- **最古老的光**：CMB，大爆炸后 38 万年发出，飞了 138 亿年，波长被拉长 1100 倍；**最远星系** MoM-z14（z=14.44，大爆炸后 2.8 亿年，截至 2026-08 仍为纪录）。
- **卫星（2026-08 普查）**：土星 285、木星 101、天王星 29、海王星 16（八大行星合计 434）；Io + 开普勒第三定律 = 木星质量 1.898×10²⁷ kg；GPS 星钟每天快 38.6 μs；系外卫星 0 确认。
- **膨胀还是缩小**：8 路独立证据全部指向膨胀（还在加速，w≈−1）；收缩证据 0 条；默认结局热寂，大坍缩需 Λ 衰变（无证据）——预测矩阵/反方出局史见 `07` §7.7–7.9。
- **前沿动态（2026-08）**：系外行星已超 6,000 颗；DESI 暗能量证据经 DES-Dovekie 修正后回落至 1.1–2.3σ（ΛCDM 回稳）；Rubin LSST 2026-06-30 开跑；Gaia DR4 定档 2026-12-02；Artemis II 已完成载人绕月（2026-04）。
