# L2 · 距离阶梯：从地球公转量到宇宙边缘

> 第一性原理问题：光速 c 给了我们"时间机器"，但要回答"这束光飞了多久"，必须先知道 **它飞了多远**。
> 天文上没有卷尺。全部距离知识建立在**一根唯一的直接标尺**上：地球公转轨道。此后每一级阶梯都靠上一级校准——这就是"宇宙距离阶梯"。

---

## 2.1 第一级：视差（几何，无假设）

**原理**：地球半年移动 2 AU（≈3 亿公里）。用这条"最长的尺"当基线看同一颗星，它相对更远的星空背景会摆一个小角度 p（视差角）。

$$d(\text{pc}) = \frac{1}{p(\text{''})}\qquad 1\ \text{秒差距} = 1\ \text{角秒视差} = 3.26\ \text{光年} = 206{,}265\ \text{AU}$$

**科学家怎么做的（贝塞尔，1838，柯尼斯堡）**：
1. **选星有讲究**：他挑了 **天鹅座 61**——因为自行极大（5.2″/yr，"跑得最快的星通常是最近的"），赌它是近星；
2. 用当时最精的自制**量日仪**连续 18 个月测它与背景星的夹角；
3. 测得 p = 0.314″ → d ≈ 3.2 pc ≈ **10.3 光年**（现代值 11.4 光年，差约 10%）。
   同期亨德森（半人马α，p=0.75″）与斯特鲁维（织女星）先后独立测成——**恒星有了尺**。

**现状**：依巴谷卫星（1993，12 万颗，毫角秒）→ 盖亚卫星（2022 DR3，**19 亿颗星**，亮星微角秒级）。
视差的极限约 1 万 pc——够到银河系内大多数星星，但到不了别的星系。**梯子必须继续搭。**

> 方法论要点：视差是整个宇宙学里**唯一无假设的测距手段**，因此它给后面每一级烛光"定标"——地基不牢，全塔皆倒。

---

## 2.2 第二级：平方反比 + 标准烛光（"同瓦数的灯，越远越暗"）

**原理**：光度 L 的光源在距离 d 的流量

$$F = \frac{L}{4\pi d^2}\quad\Rightarrow\quad d = \sqrt{\frac{L}{4\pi F}}$$

问题：星光只给 F（亮度），L（真亮度）未知。解法：**找到"出厂功率已知"的天体**——标准烛光。

**造父变星：人类捡到的第一支宇宙标准蜡烛（勒维特，1908–1912，哈佛）**

过程还原：
1. 勒维特在哈佛天文台当"计算员"，任务是在照相底片上给变星编目（她一生编了 2400+ 颗）；
2. 她注意到小麦哲伦云里的 25 颗造父变星：**同一片星云内，所有星到地球距离近似相等**——
   于是"看起来亮的 = 真的亮"，亮度和周期的关系可以**直接从视亮度读出光度规律**，完全绕开距离问题；
3. 发现：**光变周期越长，光度越大**（周期-光度关系）。周长 1 天 vs 100 天的造父，光度差几百倍。

**使用配方（沙普利、哈勃用的方法）**：
①在目标星系里找到造父变星 → ②测它的光变周期 P（只需亮度计，L0 层的时间可观测量）→
③用 P-L 关系查光度 L → ④量视亮度 F → ⑤由 $d=\sqrt{L/4\pi F}$ 得距离。

**麻烦在"定标"（整个 20 世纪天文学的坑）**：P-L 关系给出的是**斜率**，零点（截距）必须用有视差的近距造父或星团定标。
1940s 前没人知道造父有两族（经典造父 vs 短周期室女 W 型），导致哈勃把宇宙尺寸**低估了 7 倍**（见 L7）——
这是"校准链断裂会怎样"的著名教材。

**更高层的烛光**：
| 烛光 | 光度 | 最远可达 | 备注 |
|------|------|---------|------|
| 造父变星 | 10³–10⁴ L☉ | ~3000 万光年 | 哈勃望远镜逐星测 |
| 红巨星支尖端 TRGB | ~10³ L☉ | 类似 | I 波段校准，更"省事" |
| **Ia 型超新星** | **~10⁹ L☉（50 亿倍太阳）** | **百亿光年** | 白矮星吸积到 1.44 M☉ 时碳爆轰——"爆炸时的质量几乎相同，所以烛光几乎相同"（1998 年凭它发现暗能量） |

## 2.3 完整阶梯（每一级靠上一级校准）

```
AU（雷达测金星/飞船测距，米级精度）
 └→ 视差（盖亚，万秒差距内）
     └→ 星团拟合、主序拟合 → 定标造父变星
         └→ 造父 → 定标 Ia 超新星 & TRGB
             └→ Ia 型超新星 → 哈勃流 → 宇宙学模型（L7）
```

**证据链的诚实性**：每级阶梯有独立系统误差（金属丰度影响、烛光真有差别、消光改正），
现代 SH0ES 组用 JWST 复核造父定标（2023–2025），Hubble 张力（见 08 章）正说明**阶梯误差并未完全驯服**。
