## 9.2 场景/幕设计草案（与 fusion/fission app 同构：三幕 + 可点击 + 读数 + FAQ）

**第一幕 · 光与钟（L1+L2）**
- 交互：拖动"距离滑块"，屏幕上星星的"年龄徽章"实时变化（月亮 1.3 秒→太阳 8 分钟→仙女座 254 万年）
- 小实验：木卫一食计时小游戏——你移动"地球"，木卫食提前/推迟，读出 c
- 读数：视差角 → 光年；造父周期滑块 → 光度 → 距离

**第二幕 · 恒星与行星的年龄（L5+L6）**
- 交互①（星团）：拖"星团年龄"滑块，HR 图上主序从大质量端逐个"下班"，转折点发光
- 交互②（核沙漏）：U-238 沙漏翻面，读出 45.67 亿年；锆石晶体收纳 U 赶走 Pb 的小动画
- 读数：质量滑块 → 主序寿命（对数尺：红矮星 3 万亿年 vs O 星 300 万年）

**第三幕 · 来自 138 亿年前的信号（L7+L4）**
- 交互：拖"红移"滑块 z=0→14.44，一条 Lyman-α 谱线从紫外滑进红外，JWST 镜面变亮；右侧"宇宙日历"显示大爆炸后时刻
- 交互：回看时间积分可视化——光粒子从远星系飞向"现在"，身后空间在膨胀（与 gravity-slingshot 的轨迹渲染共用管线）
- 终点画面：CMB 涨落图淡入，字幕"你看到的是 138 亿年前的光"

**FAQ 候选（真实孩子问题风格）**
1. 我们能不能看到一个星系"现在"的样子？——不能，光在路上要飞；连太阳都是 8 分钟前的
2. 星星会"死"吗？太阳什么时候死？——会，太阳还剩 50 多亿年，然后变红巨星（联动 solar-cell: 想象那时的太阳能板）
3. 科学家怎么知道岩石几岁了？——铀原子像会翻面的沙漏，翻过多少次数得出来
4. 宇宙有没有"第一天"？那天留下的照片呢？——有，CMB 就是，发射于大爆炸后 38 万年
5. 为什么两个科学家量出两个宇宙年龄？——尺子还没对齐，这叫哈勃张力，他们正在比赛谁量得更准

## 9.4 需要规避的常见误区（FAQ 与文案审查清单）

1. ❌"光年是很长时间"→ ✅ 是距离（光在一年里走的路）
2. ❌"红移=星星在高速飞走（像飞机）"→ ✅ 大红移主要是**空间本身拉伸**波长（L7.2）
3. ❌"我们看到的是星星现在的样子"→ ✅ 永远是过去；参宿四可能已经爆了，消息要 600 年后才到
4. ❌"碳-14 测出了地球年龄"→ ✅ ¹⁴C 只管 5 万年内；地球年龄用的是 U-Pb（L6 常见错误）
5. ❌"宇宙膨胀是星系在空间里冲刺"→ ✅ 是空间在膨胀；本地星系群（如仙女座）还在因引力**靠近**（蓝移！）
6. ❌"太阳烧完了就熄灭变黑"→ ✅ 会膨胀成红巨星吞掉水星金星，再慢缩成白矮星
7. ❌"宇宙年龄=最远天体的距离除以光速那么简单"→ ✅ 大红移必须用回看时间积分；共动距离>光行距离（L7.3）
8. ❌"科学家已经知道一切"→ ✅ 哈勃张力、中微子背景、暗物质都在进行时——给孩子的"科学未完成感"
