# L1 · 光速有限：一切"古代信号"的物理地基

> 第一性原理问题：为什么我们敢说"望远镜是时间机器"？
> 只需要一个前提：**光不是瞬间到达的，它以有限速度 c 传播**。本章讲清 c 是怎么被人类量出来的——
> 每一次测量都是一个"用天体当日历、用三角几何当标尺"的精彩实验。

---

## 1.1 罗默 1676：用木星的月亮当秒表（史上第一次 c 测量）

**已知原料（1670 年代的观测基础）：**
- 伽利略 1610 年发现木星四颗卫星；木卫一（Io）每 **42.46 小时** 被木星遮住一次（木星食），周期极稳，像一只挂在 6 亿公里外的钟。
- 卡西尼 1675 年已编制出相当精确的木卫食表，但发现表格有"误差"：有时食发生得早，有时晚，最长能差十几分钟。

**罗默的关键推理（在巴黎天文台，向法国科学院报告）：**
这个"误差"不是钟的问题，而是**钟到观察者的距离在变**——地球在绕太阳转：
- 地球从"最靠近木星"运行到"最远离木星"（约半年），木卫食信号要多飞一段路才到我们眼里；
- 多飞的路程 ≈ **地球轨道直径 ≈ 2 AU ≈ 3×10⁸ km**；
- 累计时间差：观测到食提前/推迟的总量 ≈ **16–22 分钟**（罗默用的值约 22 分钟；现代值 16.7 分钟，因当时 AU 估小了）。

**方程与算术（课堂可直接复现）：**

$$c = \frac{\Delta L}{\Delta t} = \frac{2\,\text{AU}}{\Delta t} \approx \frac{3.0\times10^{11}\ \text{m}}{1000\ \text{s}} \approx 3\times10^{8}\ \text{m/s}$$

罗默本人得到约 **2.2×10⁸ m/s**——低了 26%，但数量级全对：**光穿过地球直径只需约 1/7 秒**，而声要十几个小时。

**方法论要点（怎么"做出"这项发现的）：**
1. 长期系统性记录（卡西尼团队十余年的食表）——数据先行；
2. 异常不被当作误差丢弃，而是寻找与已知周期量（地球公转相位）的相关性；
3. 用几何（地球轨道尺寸，当时由卡西尼测的 AU 给出）把时间差翻译成速度。
这是整个天体物理学的原型配方：**观测异常 → 几何/物理模型 → 新常数**。

## 1.2 布拉德利 1728：找视差没找到，却撞见了光行差（意外的双重证据）

布拉德利本想测恒星视差（见 L2），但发现所有恒星每年画同样大小（≈20.5″）的小椭圆——**与距离无关**，这不是视差（视差应近大远小）。

**解释：光的"雨滴效应"。** 光从上方落下时，望远镜（随地球公转，速度 v≈30 km/s）在横移，光在镜筒里飞行期间镜筒已挪动，所以必须把镜筒向前倾一个角度：

$$\tan\theta \approx \frac{v_{\oplus}}{c} = \frac{30\ \text{km/s}}{3\times10^5\ \text{km/s}} \Rightarrow \theta \approx 20.5\ \text{角秒}\ ✓$$

观测值与预测完全一致 → **第二次独立测定了 c**（且证明地球确实在公转，一石二鸟）。
方法论彩蛋：**失败实验里的"意外常量"往往是新物理**——与视差大小无关恰好说明效应来自光速本身。

## 1.3 地上测量：斐索齿轮（1849）与迈克尔逊转镜（1879）

- **斐索**：光往返 8.63 km，途经 720 齿旋转齿轮——转速调到"返回光恰好被下一个齿挡住"（12,000 转/s 量级）即可解出 c ≈ 3.13×10⁸ m/s（差 5%）。
- **迈克尔逊**：1879 年起用旋转八面镜往返 35 km 真空管（1920s），得 c = 299,796±4 km/s；他终生精修此值，实验精度成为Physics 的"金标准"。
- **1983 年起 c 不再被"测量"**：国际计量大会把米**定义**为光在 1/299,792,458 秒内走过的距离——c 从被测常数变成了定义基准。

## 1.4 推论：看任何东西都是在看过去（几何必然）

因为信号传播需要时间，t 时刻我们收到的是天体在 $t - d/c$ 时刻发出的光：

| 看什么 | 回到过去多久 |
|--------|-------------|
| 你镜子里的脸 | ~1 纳秒 |
| 月亮 | 1.3 秒 |
| 太阳 | 8 分 20 秒 |
| 海王星 | 4.2 小时 |
| 比邻星 | 4.24 年 |
| 仙女座星系 | **254 万年** |
| 仙女座星系里的造父变星 | 同样 254 万年（哈勃 1923 就靠它证明"星系宇宙"） |
| CMB（宇宙微波背景） | **138 亿年** |

**给 9 岁孩子的表述：** 天空不是"直播"，是"录播"——每颗星都是一个发光的旧照片，星越远，照片越老。
所以"望远镜看得越远"="历史书翻得越厚"。（下一章讲"多远"是怎么量的。）

## 1.5 光年：把距离单位直接写在"时间机器"上

1 光年 = 光走一年的距离 = $c \times 3.156\times10^7\ \text{s} \approx 9.461\times10^{12}$ km。
说"某星系在 120 亿光年外"时，距离与回看时间在这句话里天然合体——这正是问题 3 的直觉入口。
（注意：在膨胀宇宙中"120 亿光年外"与"光飞了 120 亿年"需用 L7 的回看时间公式严格区分，这里先建立直觉。）

## 证据小结

| 证据 | 时间 | 方法 | 结果 |
|------|------|------|------|
| 木卫一食异常 | 1676 | 天体钟 + 地球轨道几何 | c≈2.2×10⁸ m/s |
| 恒星光行差 20.5″ | 1728 | 光的雨滴模型 | c 独立复现 + 地球公转证明 |
| 斐索齿轮 | 1849 | 地面时间-飞行 | 差 5% |
| 迈克尔逊转镜 | 1879–1931 | 真空光路 | ±4 km/s → ±1 km/s 级 |
| 现代定义 | 1983 | — | c = 299,792,458 m/s（精确） |

三个完全独立的路径（天体钟、光行差、地面飞行时间）收敛到同一数量级——这就是科学意义上"确定"。
