## 0. 决策记录

**为什么是"仪器"这一刀**：仓库已有 `03-cosmic-clock` 规格讲"我们测出了什么"（光速→距离→年龄）。新需求的切入角是**过程与工具**：
"我们怎么观测"——望远镜为什么越大越强、光谱仪为什么能读出元素、干涉仪怎么用小镜子装大眼睛。
两份规格共享同一本书（006）与研究目录，但**问题域不重叠**：03 回答"这束光飞了多久"，05 回答"这束光被什么接住、怎么变成数字"。

**为什么用页签（tab）而非长章节流**：

1. **一器一页签**：每件仪器自带独立场景与交互，页签 = 注意力边界，孩子随进随出、可重玩；
2. **场景工厂可复用**：8 个页签是同一套场景工厂（光线追踪、波前环、滑块面板、读数条、粒子计数）的 8 次配置，不是 8 份代码（见 S2）；
3. **与 particle-collider 同构**：已验证的多页签 + 单文件离线构建模式直接复用，降低实现风险。

**"四可观测量"作为统一收束**：书第 1、10 章的核心洞见是"信使千变，语言唯一"——任何仪器最终输出的只有
**角度 / 时间 / 亮度（计数）/ 波长（频率）**。每个页签底部固定一条"语言条"，高亮当前仪器真正读的是哪几种。
这是全 app 的认识论骨架，也是与 03 的差异化标识。

**诚实科学贯穿**：每页签带"简化说明"徽章（哪些是示意图、哪些数字是实测）；不确定性与局限写入文案
（如 AO 只校正窄视场、宇宙线指不回源头、EHT 分辨率为有效值）。

## 1. 切割准则

- **S1 一器一页签（学习原子）**：一个页签只讲一件仪器的一个核心原理。衍射与聚光同属望远镜（同一物理的两面），故合入 T2；干涉与自适应光学虽都为"看得更清"，但原理正交（合成孔径 vs 大气补偿），拆为 T5/T6。
- **S2 场景工厂 + 配置**：所有页签共享可复用 3D 原语（见 5.1），页签模块只写配置与特有逻辑，单文件 ≤ 500 行。
- **S3 每个方程都是滑块**：θ=1.22λ/D、λmax=2.898×10⁻³/T、Δλ/λ=v/c、θ=1.22λ/B —— 出现即必须可交互驱动，且读数实时更新。
- **S4 四可测量语言条**：每页签底部固定"角度/时间/亮度/波长"四芯片，高亮本仪器实际输出的语言。
- **S5 数字可追溯**：所有展示数字列入附录 11.1，标注来源；过时性内容（如新纪录）只写"截至"体。
- **S6 零外部依赖离线**：vendor/three.min.js + js/ 模块 + build.py 生成单文件 `observatory.html`，file:// 可开。

## 3. 页签卡（三拍规格 + 数据流水线）

> 每页签一张卡，统一模板：**拍① 提问（6 s）→ 拍② 方法（14 s，原理动画 + 方程）→ 拍③ 你来玩（20 s，交互循环 + 读数 + FAQ 2 问）**。
> 每张卡含 **📐 数据流水线**：`原始读数 → 应用方程 → 逐步算术 → 真实结果`——这是本规格的强制项（回应用户
> "从得到的数据到真实结果、方程怎么用、计算过程"的要求）：每件仪器都要演一遍"数据进来→数字出去"的完整计算链。
> 每张卡末尾标注"四可测量语言条"高亮项。所有数字来源见 11.1。

### 组一 · 望：接光（金 #d8b25c）

**T1 信使全家福**

- 拍②：地球（简化半透明球）居中，五个信使从不同方向飞来：①电磁波（彩虹/射电/X 射线三束光束）②中微子（半透明"幽灵"，**直接穿过地球不回头**）③引力波（背景时空网格泛起涟漪）④宇宙线（带电粒子被磁场螺旋偏折，轨迹指不回源头）⑤样品返回舱（唯一"实物"）。
- 拍③：点选任一信使→高亮 + 信息卡（携带什么信息 / 探测器在读什么 / 打开之年：光 1609、中微子 1968、引力波 2015、宇宙线 1912、样品 1969）。
- 📐 **数据流水线（示例：中微子如何变成"方向"）**：原始读数 = 各 DOM 光电倍增管被点亮的**时刻**（纳秒）与**亮度**（光子数）→ 方程：三个以上 DOM 的到达时间差 + 冰中光速 → 三角定位反推 μ 子径迹方向 → 结果：**IceCube-170922A**（2017-09-22，能量 ≈ 290 TeV）方向定位误差仅约 0.15°，实时警报**分钟级**发出、约 4 小时后 GCN 快报精化方向；费米卫星随后确认该方向的耀变体 **TXS 0506+056** 当时正处于 γ 耀发态——人类首次把一个宇宙中微子钉到一个天体上（~3σ）。
- **语言条**：全亮；点选信使后仅亮该信使实际说的语言（中微子：时间+方向；引力波：时间+应变；宇宙线：能量+方向）。
- FAQ：为什么中微子能穿地球（弱相互作用）／为什么宇宙线指不回源头（磁场偏折）。

**T2 望远镜**

- 拍②：卡塞格林式反射望远镜剖面：抛物面主镜 + 双曲副镜 + 焦平面，平行光从左方射入，**光线追踪射线**逐根反射汇聚到焦点（焦平面处艾里斑示意）。
- 拍③：口径滑块 D 预设档（人眼 7 mm / 0.6 m / 2.4 m 哈勃 / 6.5 m JWST / 8.2 m VLT / 39 m ELT），实时读数：聚光面积比 = (D/7 mm)²；衍射极限 θ = 1.22 λ/D；极限星等 m ≈ 6.5 + 5·log₁₀(D/7 mm)（**估算式**，忽略大气视宁度与面光源限制，见 11.1）。
- 📐 **数据流水线（口径 → 看清多暗）**：原始读数 = 主镜有效直径 D 与工作波长 λ → 方程①聚光：面积比 = (D/d_eye)² → 方程②分辨：θ = 1.22 λ/D → 逐步算术（ELT：D=39 m，λ=550 nm：θ = 1.22×5.5×10⁻⁷/39 = 1.72×10⁻⁸ rad = 3.5 mas；聚光 = (39/0.007)² ≈ 3.1×10⁷ 倍人眼；ELT 官方给的自适应光学分辨指标为近红外 4–12 mas，与估算同量级）→ 结果：ELT 比人眼多收 3,100 万倍光、衍射分辨比 7 mm 瞳孔高约 5,700 倍。
- ⚠️ **防误读**：7 mm 瞳孔的**衍射**极限 ≈ 20″，但人眼实际**生理分辨力**约 1′（白天 Snellen 1.0），夜间更差——衍射不是唯一的限制。页签须把两者分开标注，不可混用。
- **语言条**：亮度 + 角度。
- FAQ：为什么用反射镜不用透镜（大口径玻璃不易铸、色差）／韦伯为什么镀金（红外反射率）。

### 组二 · 读：拆光（紫罗兰 #a78bfa）

**T3 光谱仪**

- 拍②：完整光路动画：星点 → 望远镜焦点 → 狭缝（裁出一束）→ 准直镜（平行）→ 光栅（色散展开彩虹）→ CCD（记录光谱带）。
- 拍③ 三模式切换：**黑体模式**（温度滑块 2,500–30,000 K → 普朗克亮度曲线 + 星体变色 + λmax = 2.898×10⁻³/T 读数 + OBAFGKM 指针，太阳 5,772 K = G 型）；**条形码模式**（点元素卡 H/He/Na/Ca/Fe → 吸收线亮起，Hα = 656.3 nm；基尔霍夫三定律三张脸动画；1868 太阳谱里先发现氦）；**预设恒星**（太阳 G2V / 参宿四 M / 参宿七 B 一键切换）。
- 📐 **数据流水线（光谱 → 温度）**：原始读数 = 光谱带上**亮度随波长的分布**（连续谱形状）→ 方程：维恩位移 λmax = 2.898×10⁻³ m·K / T → 逐步算术（太阳：测得 λmax ≈ 502 nm → T = 2.898×10⁻³/502×10⁻⁹ = 5,772 K）→ 结果：太阳表面 5,772 K，对应 G2V 光谱型；同一根曲线下面积积分 ∝ 总光度。成分同理：读**暗线位置** → 对照实验室元素波长表（基尔霍夫）→ 结果：太阳含氢、氦、钠、钙、铁（氦先在太阳谱发现、1895 年才在地球找到）。
- **语言条**：波长 + 亮度。
- FAQ：为什么每种元素指纹唯一（能级量子化）／星星为什么有颜色（维恩位移）。

**T4 多普勒**

- 拍②：恒星沿视线运动，**波前圆环**一圈圈发出，运动前方环压缩、后方拉疏；切换"光谱视角"，参考谱线随之左右移动，读数 v = c·Δλ/λ。
- 拍③：速度滑块 −0.1 c…+0.1 c → 波环 + 谱线 + z 值（Hα 从 656.3 nm 滑动；预设仙女座 −300 km/s 蓝移）；**系外行星模式**：恒星+行星绕共同质心，恒星"醉步"画正弦 → 谱线周期性摆动 → K 振幅读数（地球对太阳 9 cm/s、木星 12.5 m/s、51 Peg b ≈ 58 m/s），HARPS 精度线 0.97 m/s。
- 📐 **数据流水线（谱线位移 → 速度 → 行星）**：原始读数 = 谱线观测波长 λ_obs 与实验室波长 λ_0 之差 Δλ（"条形码"平移了多少）→ 方程①：v_r = c·Δλ/λ_0 → 方程②（行星）：K = 28.4·(M_p sin i)·P^(−⅓) m/s → 逐步算术（Hα 656.3 nm，测得 Δλ = +0.51 nm → v = 3×10⁵ km/s × 0.51/656.3 ≈ +234 km/s 远离；HARPS 0.97 m/s 折算位移 = 656.3 nm × 0.97/3×10⁵ = 2.1×10⁻⁶ nm ≈ 2.1 飞米）→ 结果：51 Peg b（M_p sin i ≈ 0.46 M_J、P = 4.23 d）代入 K 式得 ≈ 58 m/s（文献拟合 55.2–57.3 m/s；公式忽略了偏心率与精确恒星质量，故略偏 3–5%）→ 首颗主序星系外行星（1995，2019 诺奖）；仙女座 −300 km/s 蓝移 = 它在朝银河系飞来（45 亿年后相撞）。
  - 单位约定（K 式，来自标准天体测量式）：K = 28.4·(M_p sin i / M_J)·(P / 1 yr)^(−⅓)·(M_* / M_☉)^(−⅔) m/s——质量用木星质量、周期用**年**、恒星质量用太阳质量。预设值核对：木星 12.5 m/s、地球 9 cm/s、51 Peg b ≈ 58 m/s（文献 55.2–57.3，公式为忽略偏心率的近似）。
- **语言条**：波长（+时间，行星模式）。
- FAQ：救护车原理一样吗（是）／地球的信号多强（9 cm/s，比 HARPS 精度还弱 10 倍）。

### 组三 · 锐：合成（青 #22d3ee）

**T5 干涉仪**

- 拍②：ALMA 式阵列俯视——数台 12 m 天线接收同一波前，信号经光缆进入**相关器**（徽章 1.6×10¹⁶ 次运算/秒），合成图像随基线变锐。
- 拍③：基线滑块 B：150 m → 16 km（ALMA 构型）→ 档位跃迁到"地球级" ~10,700 km（EHT 最长基线：南极→西班牙 / 亚利桑那 / 夏威夷；站点切换为全球标注 ALMA/APEX/IRAM 30 m/JCMT/LMT/SMA/SMT/SPT）；读数 θ = λ/B（**千涉阵列的分辨约定用 λ/B，不乘 1.22**——1.22 因子属于"装满的"单口径艾里斑，阵列靠采样而非装满）；终点奖励：M87 阴影图像渐显。
- 📐 **数据流水线（两条天线 → 一张图）**：原始读数 = 每台天线收到的**电波振幅与相位**（随时间）→ 方程：相关器对两两天线做复数相关（乘 + 积分），条纹间距 ∝ 1/B；分辨 θ = λ/B（阵列约定，非 1.22λ/B） → 逐步算术（ALMA：λ=1 mm、B=16 km → θ = 10⁻³/16,000 = 6.3×10⁻⁸ rad ≈ **13 mas**；EHT：λ=1.3 mm、B=10,700 km → θ = 1.3×10⁻³/1.07×10⁷ = 1.2×10⁻¹⁰ rad ≈ **25 μas**，与 EHT 论文 II 公布的 ~25 μas 完全对上）→ 结果：2019-04-10 首张 M87 黑洞阴影照片——质量 6.5×10⁹ M☉、5,500 万光年、事件视界直径 < 400 亿 km（阴影约为视界的 2.5 倍）。
  - 公式约定（重要）：单口径望远镜用 θ = 1.22 λ/D（艾里斑半径，口径"装满"）；干涉阵列用 θ = λ/B（基线越长越锐，但只采样不装满）。页签须在两种约定之间明示切换，不可把 1.22 带进阵列。
  - 纪录对齐：ALMA 迄今最锐影像为 **5 mas**（Band 10，λ≈0.32 mm，配合 16 km 基线与 B2B 大气相位校正，观测 R Leporis 时达成）——与上式的 λ=1 mm 估算 16 mas 差 3 倍，正好演示"波长越短分辨越锐"，页签须同时呈现这两个数。
- **语言条**：角度。
- FAQ：为什么小碟子接得住（相位相关，"算出"而非"看清"）／为什么射电波段的基线能拉到公里级（波长越长，对基线稳定度的要求越宽松；光学干涉同样可行——VLTI 用 8 m 望远镜、基线到 200 m，CHARA 到 330 m，在可见/近红外达到 0.2–0.5 mas，只是光学波长短，对基线精度要求高得多）。

**T6 自适应光学**

- 拍②：大气湍流层（多层移动的畸变格）使入射波前起皱 → 无 AO 时焦面星像糊成 seeing 盘（~0.5–1″）；打开 AO：**激光导星**（589 nm 钠光射向 90 km 高空）→ 波前传感器测畸变 → **可变形镜**（镜面变形动画）实时补偿 → 星像收缩到衍射极限。
- 拍③：AO 开关，前后并排对比（模糊 vs 锐利）；湍流强度滑块控制"眨眼"速率与 seeing 数值读数。
- 📐 **数据流水线（皱波前 → 锐星像）**：原始读数 = 波前传感器上**每子孔径的光斑质心位移**（SPHERE/SAXO：41×41 Shack-Hartmann 子孔径、1,377 个驱动器、最高 1.2 kHz 采样）→ 方程：质心偏移 ∝ 局部波前斜率 → 拟合出镜面应加的**驱动器电压矩阵**（每秒解上千次线性方程组）→ 结果：8.2 m VLT 的地面分辨从 seeing ~0.8″ 压到接近衍射极限（近红外 0.02–0.05″），把恒星旁边的系外行星直接拍出来（直接成像自 2004 年 2M1207b 首张照片起；SPHERE 等仪器现为主力）。这是"地面望远镜看得像太空一样清"的完整链条。
- **语言条**：角度。
- FAQ：星星为什么会眨眼（湍流折射率抖动，太空中不眨）／为什么需要激光导星（天区多数没有够亮的天然导星）。

### 组四 · 录：成数（琥珀 #f59e0b）

**T7 探测器**

- 拍②：CCD 剖面动画：光子打入硅基底 → 产生电子-空穴对（光电效应）→ 电荷包在像素阵列中"桶列传水"转移到读出寄存器 → 模数转换成数字；PMT 模式：光子打光阴极 → 倍增级联（dynode 链放大 ~10⁶）。
- 拍③：QE 对比滑块（胶片 <5% / CCD 80–90% / PMT 单光子计数）；"光子雨"动画：稀疏光子打在阵列上累积成图像——少光子时是噪声斑点，多光子时成清晰星像，直观展示"亮度 = 计数"。
- 📐 **数据流水线（光子 → 数字 → 亮度）**：原始读数 = 每像素**电荷包的电子数**（模数转换后的整数）→ 方程：光子数 = (N_counts − N_bias − N_dark) / QE，再除以曝光时间与面积得流量 F = 光子数/(t_exp · A) → 逐步算术（**先减本底与暗流**；1,000 s 曝光、QE=0.9、收到 900 个信号电子 → 光子数 = 900/0.9 = **1,000 个光子** → 流量 = 1,000/1,000 s = **1 光子/秒**）→ 结果：星等 m = −2.5·log₁₀(F/F₀) 换算；开普勒/TESS 用同样计数法测出 6,000+ 颗系外行星的凌星深度（木星大小 ~1%，地球大小 ~0.01% ≈ 100 ppm）。
- **语言条**：亮度 + 时间。
- FAQ：为什么 CCD 取代了胶片（QE 90% vs <5%，线性、可数字化）／单光子怎么数（PMT 倍增级联把一个光子放大成可测脉冲）。

### 组五 · 闻：换信使（蓝绿 #2dd4bf）

**T8 光之外** — 三段切换（页签内子导航 A/B/C）：

- **A · 引力波（LIGO）**：俯视 4 km 双臂激光干涉仪，引力波经过时双臂交替伸缩；读数应变 h ~ 10⁻²¹；啁啾波形 GW150914（36+29 M☉ → 62 M☉，13 亿光年，2015-09-14）；展望 LISA 2.5×10⁶ km 臂（ESA，~2035）。
- **B · 中微子（IceCube）**：南极冰盖 1 km³ 剖面，86 条 string、5,160 个 DOM（1,450–2,450 m 深）；中微子撞出 μ 子 → 切伦科夫光锥（~41°）依次点亮 DOM，时间序列反推方向；KM3NeT 220 PeV 最高能中微子（2023 测到、2025 公布）。
- **C · 样品返回**：阿波罗 382 kg / 嫦娥五号 1,731 g / 六号 1,935.3 g（首份月背）/ 隼鸟 2 号 5.4 g / OSIRIS-REx 121.6 g——唯一能上手的"天文学"，同位素钟直接读年龄。
- 📐 **数据流水线（两段各演一遍）**：
  - 引力波：原始读数 = 双臂**激光干涉条纹的相位差** → 方程：应变 h = ΔL/L → 逐步算术（h ≈ 10⁻²¹、L = 4,000 m → ΔL = 4×10⁻¹⁸ m，约为质子直径的 1/400）→ 结果：从波形频率演化拟合出 36 M☉ + 29 M☉ 双黑洞并合、距离 13 亿光年，3 个太阳质量化为引力波辐射出去。
  - 中微子：原始读数 = 各 DOM **点亮时刻（ns）与亮度** → 方程：时间差 × 冰中光速 → 切伦科夫锥轴三角定位 → 结果：径迹方向 + 能量；2017 GW170817：引力波先到、1.7 s 后 γ 暴抵达——"多信使"协同定位由此成名，并独立测出 H₀ ≈ 70 km/s/Mpc。
- **语言条**：时间 + 计数（=亮度）+ 频率（=波长）。
- FAQ：为什么引力波测得了绝对距离（波形振幅含距离信息，"标准汽笛"）／中微子为什么能看进星核（不与物质反应，直接穿出）。

## 8. 性能与可访问性预算

- **帧率**：60 fps（桌面中端），每页签 draw call ≤ 60、三角面 ≤ 500k；天线阵列/DOM 阵列用 InstancedMesh。
- **切页签**：dispose 后构建 ≤ 300 ms（淡出遮罩内完成，用户无感）。
- **内存**：峰值 ≤ 300 MB（8 页签懒构建，同时只活 1 个场景）。
- **可访问性**：所有滑块可键盘操作（←/→ 微调）；数字读数为 `aria-live` 区域；对比度 ≥ AA；尊重 `prefers-reduced-motion`（自动播放降速 / 关闭晕影）；不依赖颜色单独传达信息（语言条芯片带文字）。
- **包体**：vendor three.min.js 651 KB 不动；js/ 源码合计 ≤ 3,000 行；生成的 observatory.html ≤ 1.2 MB。

### 11.4 术语表（领域模型 · CONTEXT）

> 本规格的领域语言。术语在页面文案与代码命名中必须与此处一致；发现歧义即改此处（domain-modeling 纪律）。

| 术语 | 定义 | 边界 / 反例 |
|------|------|------------|
| **可观测量（observable）** | 仪器最终吐出的四类原始数字之一：**角度 / 时间 / 亮度（计数）/ 波长（频率）**。偏振是"第五路免费信息"，本规格只在 T1 提一句不展开 | 不是"物理量"：温度、质量、距离、年龄都是**推导**出来的，不是可观测量 |
| **信使（messenger）** | 把宇宙信息送到地球的五种载体：光（电磁波）、中微子、引力波、宇宙线/高能 γ、样品 | 信使 ≠ 仪器：光子是信使，望远镜是读信的机器 |
| **语言条（language bar）** | 每页签底部四芯片（角度/时间/亮度/波长），高亮当前仪器真正输出的那几种 | 高亮项必须与该仪器实际读数一致（如 T4 亮"波长"，T8 亮"时间+计数+频率"） |
| **原始读数（raw reading）** | 数据流水线第一段：仪器直接测到的量（谱线位置、DOM 点亮时刻、相位差……） | 不是结果："+0.51 nm"是读数，"+234 km/s"是结果 |
| **数据流水线（data pipeline）** | 本规格的核心教学组件：原始读数 → 应用方程 → 逐步算术 → 真实结果，四段竖排实时更新 | 每段必须有数字、单位、来源标号；滑块拖动时四段同步 |
| **真实结果（published result）** | 流水线终点：对标的真实天文学发表数字（51 Peg b 的 55.2–57.3 m/s、M87 的 6.5×10⁹ M☉） | 必须标"截至"日期与来源；不得用动画虚构值冒充 |
| **拍（beat）** | 页签内的最小教学单元：①提问 6 s / ②方法 14 s / ③你来玩 20 s | 拍③ 手动模式无限循环；换页签即重置拍索引 |
| **页签（tab）** = 仪器 | 一件仪器一个页签，自带 3D 场景 + 流水线 + 语言条 | T8 是例外：一个页签装三个"非光信使"子段 A/B/C |
| **衍射极限 vs 视宁度（seeing）** | θ=1.22λ/D 是**望远镜的物理下限**；seeing 是**大气**造成的模糊下限。AO 把地面拉近衍射极限 | 不可混用：7 mm 瞳孔衍射 20″ ≠ 人眼生理分辨 ~1′ |
| **示意图（schematic）** | 所有 3D 场景的性质：比例与结构经简化，非实时观测数据 | 每页签右上角必须挂「示意图 · 非实时数据」徽章 |
