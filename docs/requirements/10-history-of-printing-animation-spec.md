# 10 · 印刷史 printing 家族 · 完整规格 v1.2（需求 / 架构 / 设计 / 计划）

> **一句话**：**8 个独立动画项目、28 个电影感场景**组成的 `printing` 家族——把"知识怎么被复制"
> 的发展史拆成 **1 个枢纽（五千年时间轴 + 四大印版总览 + 三大规律）+ 7 件"一次跃迁"动画**：
> 雕版怎么刻反字 → 活字怎么拆了重排 → 谷登堡怎么铸出几十万颗一样的铅字 → 蒸汽与铸排机怎么提速 →
> 胶印怎么靠"油水不溶"印出全彩 → 激光打印机怎么用静电每页重刻一次"版" → 3D 打印与 EUV 光刻
> 怎么把"印"变成"造"。每个场景默认**自播循环 + 微距拍点**，孩子可随时上手：
> 反贴纸张、合金配比、活字拼句、转轮检字、激光扫描、网点混色……
> **依据**：`jennings-site/src/content/book/008-history-of-printing.typ`（全书 15 章 + 附录大事年表）；
> 一手来源核实见附录 11.1/11.4（2026-10-12 在线深研）。
> **同族先例**：`05-observatory-3d-animation-spec.md`（三拍规格与场景工厂骨架）、
> `common/js/nuclide.js`（跨项目共享模块先例）、`solar-cell/build.py`（esbuild 单文件构建，
> 已验证可打包 `../../common/` 相对导入）。

## 1. 切割准则

- **S1 一项目一次跃迁**：7 个开发动画各回答一次"复制方式的跃迁"。凹版/孔版无独立跃迁故事，
  归入枢纽；王选拼入 `printing-digital`；雕版/活字/谷登堡分别对应"固定→重组→金属系统化"。
- **S2 场景预算**：每项目 **3–4 个场景**（枢纽 3 个），全家族 28±2 个；每场景一个拍点；
  场景文件 ≤ 500 行；场景 = 全屏视口级舞台，项目内步骤式推进（非页签切换）。
- **S3 每个机制都是可操作的**：交互是增强，自播是默认（D8③）；读数实时更新。
- **S4 版性条全局一致**：三芯片取值域固定；枢纽时间轴每代技术携带同一芯片。
- **S5 数字可追溯**：所有展示数字列入 11.1 标 PROV；无来源不展示或标"示意"。
  速度阶梯锚点：**250 → 1,100 → 8,000 → 20,000** 页/时（全部 certified，见 11.1）。
- **S6 零外部依赖离线 + 全量 Three.js 3D**：统一页 `printing/index.html` 通过 importmap 挂载本地 `./vendor/three.module.js`（REVISION 160）；**全部 7 个阶段、25 幕正片（W1–F3）100% 采用 Three.js 3D 空间机构渲染 + 2D HUD 微视窗叠层**。
- **S7 家族共享层**：跨项目复用放 `common/js/printing/`（plateBar / speedLadder / familyNav / sound / textures / sceneKit），
  项目私有逻辑放各自 `js/`，禁止复制粘贴共享逻辑。
- **S8 覆盖守恒**：书 15 章 50 余节每节有且仅有一个"所属场景"（§2.2 + G23）；
  枢纽只做摘要与总览，深度归各项目——"摘要 vs 深度"不算重叠。

### 5.3 3D 空间机构架构（v3.0 全量 Three.js）

1. **共享单 WebGLRenderer 防上下文耗尽**：
   - 浏览器限制单页最多同时存活 8–16 个 WebGL 上下文；25 个 Tab 若各自 `new THREE.WebGLRenderer()` 会触发 `Context Lost`。
   - `sceneKit.js` 的 `stage3d(parent, opts)` 采用**全局单例 `THREE.WebGLRenderer` + 缓存 `PMREM` 环境贴图**，每个场景拥有独立的 `THREE.Scene`、`THREE.PerspectiveCamera`、3D 机构对象树与上层透明 2D HUD `<canvas>`；当某 Tab 触发 `onShow()` 时，共享 WebGL 画布自动挂载至当前舞台底层并启动 `requestAnimationFrame` 渲染。
2. **双层协同渲染（3D 空间机构 + 2D 微距放大镜 HUD）**：
   - 底层 WebGL 画布负责呈现**真实三维空间关系**：立体凸版反字高度差、180° 空间翻纸反贴、凿刀剔除木料、三维窑炉烧结、双铁范交替、三维钢冲/铜模/手铸模浇铅、螺旋木压机丝杠、平压平/平压圆/圆压圆啮合、Linotype 90 槽斜置字模库与双楔铁、三滚筒胶印对滚、四色胶印机组流水线、三维感光硒鼓六工位旋转、热发泡/微压电三维喷嘴剖面、万字立体铅架矩阵、三维贝塞尔字形扫描、3D 打印喷头逐层堆叠、EUV 布拉格多层反射镜光路与纳米压印模板。
   - 顶层透明 2D HUD 画布负责呈现**高清文字标注与右上角 `🔍` 微视窗放大镜（`drawMacroInset`）**，做到“3D 宏观运动可 360° 拖拽观察，微观物理切面清晰可读”。
3. **内置 3D 交互相机（Orbit Rig）**：
   - 支持鼠标/触控拖拽围绕目标中心旋转俯仰（`azimuth / polar`），滚轮缩放视距（`radius`），双击舞台或点击右上角 `🎥 3D 视角复位` 按钮平滑插值回到最佳机位；闲置时相机带微幅呼吸摆动。

## 6. 视觉规范（电影感与易懂性）

### 6.1 气魄（Grandeur）

- **全量 Three.js 拟物写实材质（D9 / v3.0）**：全部 25 幕 3D 机位使用 `THREE.MeshStandardMaterial` / `THREE.MeshPhysicalMaterial`（金属高 metalness、木材/陶土/纸张真实 roughness 与凹凸贴图）+ 影棚三点灯（主光 Key / 补光 Fill / 轮廓光 Rim）+ **PMREM 程序化环境反射**（§5.3，零外部文件）；
  木纹、金属拉丝、纸纤维、立体字模贴图全部由**程序化 canvas 纹理**生成并缓存复用。
- **全屏 3D 舞台**：每场景占满主视口（高度 300 px）；支持 3D 自由旋转观察与步骤轨道联动。
- **拍点制度**：每场景一个拍点（§3 🎬），拍点用**3D 机位推轨 + 慢动作物理接触 + 3D 粒子强化**三件套。
- **自播循环**：所有 3D 机制演示默认自播循环（不点击也在动），交互（3D 旋转/滑块/按钮）随时接管——
  保证"打开即有直观 3D 动画"。
- **氛围层**：每场景配备 3D 空间悬浮微粒（工坊光尘 / 窑火火星 / 水雾微滴 / 激光光子），≤ 300 粒。
- **规模奇观**：大数字用 3D `InstancedMesh` / `Points` 规模可视化（25.3 万活字立体书山 / 万字三维铅字架矩阵 / 60 层 3D 花瓶逐层生长）。

### 6.2 清晰易懂（Clarity）

- **三拍结构**：每场景 提问 → 原理 → 你来玩，固定版式；
- **3D + 微视窗同屏**：3D 主舞台呈现立体机械动作，右上角 2D HUD 微视窗放大镜（`drawMacroInset`）同步呈现微观物理（薄如钱唇 / 药剂固版 / 网点玫瑰斑 / 静电潜像 / 皮升墨滴 / 锑膨胀 V 槽 / 纳米压印）；
- **步进编排**：每场景 3–6 步，顶部药丸轨道高亮当前激活工序；
- **材料即颜色**：实物 PBR 色系（梨木棕/枣木红/黄铜金/铅锑银灰/石灰石青灰/橡皮布海蓝/宣纸米白/松烟墨黑）。

### 6.3 一致性

- 五段代际色（= 时间轴色带 = 项目主题色，§2.1）；字体走系统栈 + i18n；3D 凸版反字用镜像几何或 `scale(-1,1)` 贴图现场生成；读数 `tabular-nums`；对比度 ≥ 4.5:1；触控目标 ≥ 44 px。

---### 6.4 声音设计（D10）

- 音色表（全部 WebAudio 程序化合成，零音频文件）：浇铅嘶响（滤波噪声衰减）/ 压机落印（低频
