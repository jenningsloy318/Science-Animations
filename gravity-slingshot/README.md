飞掠轨道不再是示意曲线，而是**真实的双曲圆锥线**：

```
r(ν) = p / (1 + e·cosν),  e = 1 + rp·v∞²/μ,  转角 δ = 2·arcsin(1/e)
相对速度沿双曲线按能量守恒变化: v(ν) = √(v∞² + 2μ/r)
```
