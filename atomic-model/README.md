# ⚛️ 原子模型 · Atomic Model — 3D 交互（玻尔 ↔ 电子云）

以氢原子为主角的原子结构交互教学：光子吸收/发射、电离与电子捕获、
**真实氢原子谱线**（里德伯公式）与**电子云**（量子力学概率密度）。

> **入口**：`index.html`（模块化，需本地 http 服务）/ `atomic-model.html`（单文件离线版）

## 真实谱线（node 测试 6/6 验证）

- **莱曼系**（→n=1，紫外）：Lyman-α **121.6 nm**（10.2 eV）……系限 91.2 nm
- **巴耳末系**（→n=2，可见）：Hα **656.3 nm 红** · Hβ **486.3 nm 青蓝** · Hγ 434.2 · Hδ 410.3
- **帕邢系**（→n=3，红外）：Paschen-α **1875 nm**
- 公式：1/λ = R_H(1/n₁²−1/n₂²)，R_H = 1.0967758×10⁷ m⁻¹；E_n = −13.5984/n² eV
- 波长为**真空值**（应用显示 Hα = 656.5 nm；习惯引用的 656.3 nm 是空气波长，差 0.03%）
- 试一试：选中 **H** → 连按两次"吸收光子"：第一次吸收 **121.6 nm 紫外**（n=1→2），
  第二次吸收 **656.3 nm 红光**（n=2→3，就是巴耳末 Hα！）——吸收与发射波长相同。

## 诚实标注

- **玻尔模型是简化**：真实原子中电子不是跑圈的小球——切"☁️ 电子云"看量子力学画像。
- **多电子元素**（He/O/Si/Fe）的真实谱线是复杂的多体问题，本应用的光子能量/能级图为
  玻尔式示意（界面上标注"示意"）。
- 核子（质子/中子）画成刚性小球，真实核子由夸克构成。
